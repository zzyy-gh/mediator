# Tools and Prior Art — Investing

Probe-target for external lookup before treating any thesis as novel. Append on encounter.

## Quantitative methods

- **Kelly criterion** — position sizing under known edge.
- **Black-Litterman** — Bayesian portfolio construction blending priors with views.
- **Mean-variance optimization** (Markowitz) — efficient frontier.
- **Risk parity** — equal risk contribution across assets.
- **Factor models** (Fama-French, Carhart, Barra) — decompose returns into exposures.
- **HMM regime detection** — Markov-switching for regime classification.
- **Cointegration / pairs trading** — stationary spread between non-stationary series.
- **Bayesian shrinkage** for return estimates (James-Stein, Ledoit-Wolf).

## Frameworks and shops

- **Multi-manager pod model** (Citadel, Millennium, Point72) — central risk, decentralized PMs.
- **Bridgewater Pure Alpha** — systematic with discretionary regime overrides.
- **Renaissance Medallion** — short-horizon statistical arbitrage.
- **AQR / DFA** — academic-factor-driven systematic.

## Data sources

- Bloomberg, Refinitiv, FactSet — institutional terminals.
- IEX, Polygon, Alpaca — retail / dev-friendly APIs.
- SEC EDGAR — filings.
- FRED — macro series.
- CBOE — options and vol data.

## Risk concepts

- VaR, CVaR — tail-risk measures.
- Drawdown, ulcer index — pain measures.
- Sharpe, Sortino, Calmar — risk-adjusted return ratios.
- Beta, factor exposure — implicit-bet detection.

## Behavioral

- Kahneman / Tversky biases relevant to trading: anchoring, recency, narrative bias, disposition effect, loss aversion.
- Soros reflexivity — feedback between beliefs and prices.
